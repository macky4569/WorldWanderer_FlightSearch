# FlightSearchProject

## Overview
`FlightSearchProject` is a Java project that simulates flight search validation for the WorldWanderer website.  
The project includes:

- `FlightSearch.java`: Handles flight search logic and validations.
- `FlightSearchTest.java`: Unit tests for `FlightSearch` using JUnit 5.

---

## Features
- Validates total passenger count (1-9 passengers).
- Ensures children and infants follow seating rules.
- Validates child-to-adult and infant-to-adult ratios.
- Checks date formats and ensures departure/return dates are valid.
- Validates airport codes and seating classes.
- Supports emergency row seating restrictions.

---

## Prerequisites
- Java 17 or higher
- VS Code (recommended) with **Java Extension Pack**
- JUnit 5 standalone JAR
